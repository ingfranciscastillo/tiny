## Description

tiny is a collection of 136 small, fast browser-based tools for JSON, text, encoding, images, and everyday dev tasks. Every tool runs entirely client-side — nothing you type, paste, or upload is ever sent to a server.

> [!NOTE]
> No sign-up, no backend, no tracking. Open a tool and use it.

## Features

- **136 tools, one place** — spanning JSON & data, text, development, encoding, images, and design utilities, plus a curated popular set on the home page.
- **Runs entirely in your browser** — every conversion, format, and generation happens client-side; your input never leaves your device.
- **Instant search** — jump to any tool with `⌘K` / `Ctrl K`.
- **Light & dark themes** — follows your preference, remembered across visits.
- **No account, no setup** — open a link and start working.
